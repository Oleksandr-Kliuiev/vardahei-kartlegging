# Дизайн Varde: эталон «Vardestien»

Концепт принят Oleksandr 15.10.2026 (`docs/BESLUTNINGER.md`, `PRINCIPLES.md` «Визуальный стиль»). Он заменяет решение 11.10 о стиле kartlegging 1:1. Внедрение — checkpoint 1e в `STAGES.md`.

Опубликованная версия (v4, приватная, открывает владелец): https://claude.ai/artifact/3X2D5ZMasH85sRMBk2FSe9. Файлы в `vardestien/` совпадают с ней.

## Что внутри

| Файл | Что это |
| --- | --- |
| `vardestien/index.html` | Страница концепта (по-русски): идея, движение, токены, основы, карта продукта, решения |
| `vardestien/sporjeskjema.html`, `sporjeskjema.js` | Прототип runner на нюношке: все экраны, ландшафт с камерой, турист, варды, вершина |
| `vardestien/admin.html`, `admin.css`, `admin.js` | Прототип админки на нюношке: все разделы, ⌘K, «Send ut», живые тропы |
| `vardestien/varde.css` | Токены и база: шкалы цветов, семантика light/dark, зоны, ландшафт, движение, кнопки, чипы |
| `vardestien/varde-motion.js` | Кривые, пружины, tween, FLIP, stagger, countTo, View Transitions, reduced motion |
| `vardestien/survey-data.js`, `admin-data.js` | Данные прототипа. Вопросы — из шаблона «tryggleik»; числа и события админки выдуманы |

Открыть локально (iframe и postMessage работают только с сервера):

```bash
python3 -m http.server -d docs/varde/design/vardestien 8080   # http://127.0.0.1:8080
```

В прототипе runner слева у края есть ручка «Prototype»: переход на любой экран, тема, «Sakte ×4» и «Redusert», ошибка отправки.

## Что обязательно, а что нет

Обязательно для кода: токены и их значения, шрифты, кривые и длительности, поведение движения (что, когда и после чего двигается), раскладка экранов, тексты на нюношке, правила доступности (фокус, reduced motion, зоны словом и цветом), k-подавление «–» в интерфейсе.

Не обязательно: структура файлов и имена функций прототипа, данные, ручка «Prototype», точные пиксели там, где код Varde даёт свою сетку. Прототип на чистом JS, без сборки; в Varde то же переносится в Preact (runner), React (admin) и пакет `@varde/ui`.

Разделы «Seminar», «Assistent» и «Rapportar» — дизайн для этапов 2b, 3 и 5; в 1e не внедряются.

## Как проверять движение

Скриншотов мало: рывки видны только в движении. Для runner — покадровая запись (позиции туриста, пузыря, руки, камней, время от ответа до первого движения) и киноленты в «Sakte ×4» для ключевых моментов: старт, остановка у варды, смена роли на «Leiar», «Ta dei med», отправка и вершина, в светлой и тёмной теме, на 390 и 1280 px.
