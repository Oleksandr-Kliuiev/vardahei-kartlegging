# Этапы сборки Varde

Черновик после раунда 2, с delta 12.10 (ADR-025, ADR-026): решения Oleksandr 12–13.10 внесены как решённые (анонимность — выбор перед стартом опросника, вариант B для всех раундов, правило (a) для руководителей, бессрочное хранение с удалением и возвратом по требованию, букмол по переключателю); открытых пометок нет. Задача = 1–3 часа работы Opus 5.5 (medium) с тестами, один коммит. Перед этапом Fable пишет `stages/stage-N.md` с теми же задачами, обязательными тестами и списком «не входит». Размер: S — дни, M — неделя, L — две и больше. Колонка «ч» — часы кодера; календарное ожидание внешних входов — в таблице ниже, не в часах.

## Протокол checkpoint

- Checkpoint закрывается пакетом доказательств `stages/stage-N/<cp>-evidence.md`: artifact hash (commit), команды проверки с ожидаемым выходом, hash использованных fixtures, список согласованных отклонений паритета, статус внешних входов, перечень инвариантов, проверенных в этом checkpoint.
- Приёмка: GPT-6.1 Sol (xhigh) и Opus 5.5 (xhigh), чистые сессии, по одному и тому же artifact hash, вход — только репозиторий, `docs/` и пакет этапа; отчёт кодера читается последним. Checkpoint закрыт, когда у обоих нет blocking и important замечаний.
- Зависимая работа следующего checkpoint не начинается до двух approvals предыдущего. Параллельно допускаются только независимые внешние входы (перевод носителем, сбор метрик VPS, чек-листы) и задачи, не зависящие от незакрытого кода.
- Инварианты проверяются в checkpoint, где появляется соответствующий код; последняя задача каждого checkpoint — его тесты инвариантов.
