# ADR-015: SSE — уведомление для админки, отдельный поток для экрана ведущего

Статус: Accepted (дополнение Astra принято)

## Контекст
SSE остаётся вместо WebSocket. Один общий поток, который пушит состояние, смешивает данные админки (прогресс, выводы) и зала (результаты голосования) и усложняет reconnect.

## Решение
- Админка: поток событий вида `{type, id, at}` («изменилось») без данных; клиент перечитывает состояние обычным API через TanStack Query. Один канал на пользователя.
- Экран ведущего: отдельный поток на конкретный live poll, авторизованный presenter-token; передаются только released-результаты вопроса после его закрытия ведущим и уже прошедшие `privacy`; при reconnect клиент получает snapshot текущего состояния и продолжает.
- Участники live poll не получают SSE; они отвечают через runner и видят результат на экране.

## Альтернативы
WebSocket (двунаправленность не нужна); пуш полного состояния (гонки, дубли, утечки).

## Последствия
Простой reconnect; экран ведущего не может случайно получить сырые ответы. Цена: M (в этапе 3).
