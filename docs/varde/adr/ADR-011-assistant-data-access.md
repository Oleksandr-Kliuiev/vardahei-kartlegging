# ADR-011: Что видит ассистент — агрегаты через privacy и выдержки, проверенные человеком

Статус: Accepted (позиция Fable изменена по возражению Astra)

## Контекст
Fable: агрегаты всегда; свободный текст после regex-очистки имён, почт и номеров. Astra: regex не убирает косвенную идентификацию (должность, событие, клиент в контексте); облачный проход «для очистки» уже передаёт сырой текст провайдеру; при шести малых клиентах ручная подготовка дешевле. Агрегаты тоже могут раскрывать человека при малых n.

## Решение
- Контекст ассистента в v1: агрегаты и выводы, выданные модулем `privacy` (с тем же порогом, что для дашборда); выдержки из свободных ответов, которые человек подготовил вручную и пометил как проверенные (без пары «клиент + роль» в одной записи); стилевой гайд, глоссарий, библиотека вопросов; прошлые семинары.
- Умение «краткое содержание свободных ответов» из этапа 2 убрано. Умение «объяснение вывода» работает на snapshot и проверенных выдержках; цитаты по умолчанию не включаются.
- Возврат автоматической обработки свободного текста возможен только через новый ADR при трёх условиях: уведомление респондентам v2 называет AI-обработку; человек видит и подтверждает каждый пакет текстов перед отправкой провайдеру; ответ Oleksandr на вопрос о модели угроз (спор 21) это допускает.
- Формулировка «агрегаты — всегда» заменена на «агрегаты — через privacy».

## Альтернативы
Regex-очистка (ложная уверенность); модельная очистка (передача сырого текста провайдеру); сырые ответы (неприемлемо).

## Последствия
Этап 2 теряет одно умение; команда читает свободные ответы сама (при ~60 респондентах — десятки коротких текстов за раунд). Появляется небольшой UI выдержек в этапе 2. Цена: M относительно исходного плана за счёт UI, минус работа над очисткой.
