# ADR-012: Proposal привязан к точной ревизии исходника

Статус: Accepted (дополнение Astra принято)

## Контекст
Результат ассистента — всегда предложение; человек принимает, правит или отклоняет. Без привязки к ревизии предложение, сделанное для старого текста вопроса, можно принять поверх нового.

## Решение
- Proposal хранит `input_hash` (hash исходного черновика/запроса и контекста), `output_hash`, модель, версию промпта, стоимость, статус, кто и когда решил.
- Изменение исходника после генерации переводит Proposal в `stale`; принять его нельзя, можно перегенерировать.
- Принятие создаёт новую ревизию черновика (с ссылкой на Proposal); публикация — отдельное действие человека с проверкой переводов (ADR-019).
- Статистика принятия (без правок / с правками / отклонено) считается по этим статусам.

## Альтернативы
Прямое применение с подтверждением (нет следа, нет защиты от устаревания).

## Последствия
Тест: «правка вопроса после генерации → Proposal stale». Цена: M (hash-и, статусы, UI).
