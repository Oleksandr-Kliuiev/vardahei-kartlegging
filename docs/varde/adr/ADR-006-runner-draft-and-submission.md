# ADR-006: Раннер — контракт черновика и надёжной отправки (решения 6 и 23)

Статус: Accepted (дополнение Astra принято)

## Контекст
Runner должен переживать плохой интернет. Сейчас `server.js::/api/svar` на каждый POST создаёт новый UUID, а `valider()` проверяет допустимость значений, но не путь показа; повтор запроса после потери HTTP-ответа создаёт дубль.

## Решение
Черновик:
- Ключ в localStorage = `varde:<round_client_code_hash>:<template_version>`; TTL = срок RoundClient; удаляется после подтверждённой отправки; черновик другой версии игнорируется.
- Обещание: восстановление после перезагрузки страницы и обрыва связи, пока браузер хранит данные. Полный offline (service worker, отправка позже) в этап 1 не входит.

Отправка:
- Общая часть и часть руководителя — две независимые отправки. Клиент генерирует два случайных `submission_id` (по одному на часть) при старте черновика и хранит оба в черновике; общего ключа между ними нет ни в запросе, ни в базе.
- Сервер: уникальный индекс по `submission_id` и сохранённый `content_hash`. Повторный POST с тем же id и тем же hash возвращает тот же результат (201 + тот же ответ) и не создаёт строки; тот же id с другим содержимым → 409. Квота RoundClient расходуется при вставке строки, не при запросе, поэтому replay её не тратит. Транзакция «проверить → записать → ответить».
- Сервер повторно вычисляет путь показа по `rules/runner`: ответы на невидимые вопросы отбрасываются, `exclusive_options` и `choices_from` проверяются, `template_version` берётся из RoundClient, а не из тела запроса.
- `submission_id` не связан с Contact, Registration или ProgressEvent.

## Альтернативы
Серверный UUID (дубли при повторе); персональные токены (конец анонимности, решение 9).

## Последствия
Тесты: «повторный POST создаёт одну запись и не тратит квоту», «тот же id с другим содержимым → 409», «потеря ответа после commit → повтор возвращает успех», «ответ на невидимый вопрос отбрасывается», «две части не имеют общего ключа». Общая ссылка по-прежнему не защищает от повторного участия одного человека — это не обещается.
