## Что делает Oleksandr

1. Проходит строки сверху вниз: открывает ссылку или Console, сверяет формулировку, при расхождении пишет факт в колонку «Где подтверждение».
2. Делает скриншоты из колонки по правилу выше, кладёт в `0.13/` и сам смотрит каждый файл перед `git add`.
3. Меняет статус на `ok` (или `fail` с причиной) и пишет «Oleksandr, ДД.ММ.ГГГГ».
4. Решения, которые остаются за ним: ZDR (строка `zdr`), передача в США (строка `location`, правка `docs/personvern.md`), субподрядчик в databehandleravtalar с клиентами (строка `dpa`).
5. Когда `pending` не осталось — строгий режим теста зелёный: `cd varde && pnpm --filter @varde/tools-docs test -- anthropic-checklist --require-complete`.
