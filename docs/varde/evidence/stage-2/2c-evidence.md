# 2c — мастерская опросников: evidence

## 2.15 — ядро мастерской

Ветка `varde/verkstad-1` (от `main` a0c7b79). Концепт и решения 1–7 — `design/admin-konsept/`, `BESLUTNINGER.md` (17.10).

### Что сделано

- Страница `/admin/surveys/<версия>` в три панели: тропа (разделы-варды, «Berre for leiarar», узлы «Om skjemaet», «Velkomen», «Invitasjon og plakat», «Råd på slutten»), вопрос, телефон.
- Тропа: поиск, перетаскивание, Alt+↑/↓, «+ Spørsmål» в активном разделе, «Ny seksjon»; выбранная строка не прячется под поиском.
- Вопрос без ID и JSON: тип, текст (растёт по содержимому), ответы с риском 0–3, «Må svarast», «Kven får», условие фразой («Blir berre vist når F14 «Brukar MFA» er «Nei».»), «Brukt i»; «Teknisk» (ID, якорь, JSON) свёрнут.
- Телефон стоит на выбранном вопросе (на 1280 px — уменьшенный, уже 1130 px — за кнопкой «Telefon» с крестиком); скрытый условием вопрос показан с пояснением; ответы в телефоне ведут тропу; повторный клик по вопросу возвращает телефон к нему.
- Автосохранение через 0,7 с по `content_hash`; 409 — «Hent det lagra utkastet» (два клика) / «Lagre mine over», ввод не теряется (копия в браузере); ⌘Z/⇧⌘Z; «Angre» в тосте возвращает именно удалённый вопрос. «Ikkje lagra · Vis kva som manglar» ведёт к полю, которое мешает сохранению.
- F1–F22: замок до «Rett ordlyden», затем «Rettskriving / Ny meining» с diff; «Ny meining» даёт новый `anchor_key` (`F5~v3`); «Rettskriving» действует для той формулировки, для которой выбрана.
- Панель публикации: проблемы с местом словами («Kontakt: e-post», «F5: svar 2») и «Gå til», F-вопросы, корректура nn, перевод en, удержание кнопки; причина неактивной кнопки видна; панель модальная (фон inert, Escape, фокус возвращается).
- Опубликованная версия — только чтение и «Lag utkast vN» / «Opne utkastet vN»; на странице «Skjema» — один черновик на опросник (решение 3).
- Решение 5: новый опросник создаётся с разделом «Om deg», вопросом роли и (при «Med initialar») вопросом инициалов — тексты из утверждённых сидов (nn, en). Переключатель «Identifikasjon» сам добавляет вопрос инициалов первым или убирает его; при зафиксированном вопросе инициалов переключатель закрыт с объяснением. Раньше «Anonym» при существующем вопросе инициалов давал черновик, который нельзя было сохранить без JSON.
- API: черновик сохраняется неполным (нет языка, роли, текста); битая ссылка и сломанная структура — 400, как раньше (решение C, 17.10). Раннер: сообщает только перемещения телефона; для ещё не показываемого черновика пишет «Sjå kva som manglar», а не «krev innlogging».

### Независимое ревью (агент, только чтение) — найдено и исправлено

- Повторное открытие черновика из кэша давало старую копию и хеш: следующая правка получала 409 против самой себя, а «Lagre mine over» затирал прошлые правки. Теперь мастерская открывается только со свежих данных сервера (после незавершённого сохранения), каждое сохранение кладётся в кэш.
- Сервер считал заголовок раздела изменением F-вопроса: перенос F-вопроса в начало раздела или переименование раздела блокировали публикацию без возможности отметить. Сервер теперь сравнивает без заголовка раздела (тест API, мутационная проверка).
- Восстановление копии из браузера шло с новым хешем и могло молча затереть чужое сохранение; теперь копия хранит свой хеш и идёт через выбор при конфликте.
- Уход из мастерской внутри приложения в первые 0,7 с терял набранное; теперь сохраняется.
- Два ожидающих сохранения уходили с одним хешем (ложный 409); теперь сохранения строго по очереди.
- Телефон держался за номер шага: при переносе вопроса выделение в тропе прыгало на соседний; теперь держится за сам вопрос.
- Смена вопроса в правиле условия стирала правило; удалённый ID мог достаться новому вопросу («Angre» тогда молча ничего не делал); ⌘Z работал в опубликованной версии; безымянный первый раздел при перемещении сливался с соседом. Всё исправлено, на каждое — тест; ключевые проверены мутациями (тест падает на старом коде).

### Найдено и исправлено по ходу

- Телефон при загрузке сообщал «я на старте» и перебивал выбранный вопрос; подтверждение собственной команды перебивало выбор раздела.
- 1280 px: телефон был скрыт. 761–1048 px: одна колонка без прокрутки страницы обрезала редактор. Теперь ярусы считаются по ширине мастерской и панели редактора (container queries), окно заполняется flex без «лишних» пикселей.
- Метка `.sr-only` выпадала из прокручиваемой панели и удлиняла страницу (`position: relative` на панелях). Проверки `escaped-abs`, `near-fit`, `textarea-clipped` добавлены в `ui-layout-audit`; последняя нашла обрезанные тексты «Kva vi gjer» на «Funn» — исправлено тем же правилом.

### Риски и ограничения

- Проверено в Chromium. Safari и Firefox не проверены: `zoom` телефона, `field-sizing` (в Firefox поле не растёт, остаётся прокрутка), `:has()`, `inert`.
- Выбор «Rettskriving» хранится в этом браузере до публикации; в другом браузере его надо сделать снова (сервер без выбора не публикует).
- Один черновик на опросник — правило интерфейса; в API — с 2.16.
- Новый опросник сохраняется, только когда заполнен контакт на «Velkomen» (контакт по умолчанию — 2.16); до этого статус «Ikkje lagra · Vis kva som manglar».
