# Что изменилось после rev 33 архитектуры Varde

Документ «Архитектура платформы Varde» (rev 33, 11.10.2026, копия рядом: `varde-arkitektura.md`) написан до изменений 12.10. Перед brainstorm с Astra его нужно поправить:

1. **Анонимность (решения 9, 11, модель Response, риск «Анонимность при росте функций»).** Опросник по безопасности теперь спрашивает инициалы и показывает результаты по сотруднику; KI-опросник остался анонимным. В Varde анонимность должна быть свойством шаблона или раунда (`identifikasjon: none | initialar`), а не всей системы. Порог `minGruppe` нужен только для анонимных раундов. Ответы с инициалами — персональные данные: срок хранения, реестр обработки.
2. **Модель зон = первые FindingRule.** Цвет у каждого варианта ответа (0–3), snittscore, kritisk andel, разные пороги для человека и для агрегатов (`docs/sonemodell.md`). В модели данных: `farge` на уровне варианта в TemplateVersion, `SoneModell {person[], samla[]}` на уровне шаблона или организации. Решение 5 (JsonLogic) этого не покрывает: это таблица соответствий, а не выражение.
3. **Импорт прошлых раундов.** Раунд 1 пришёл из Forms/Excel (57 ответов). В этапе 1 нужен импорт «внешний раунд» с сопоставлением вопросов и вариантов (`tools/runde1_fra_excel.py` — прототип).
4. **Сравнение раундов по людям.** Связь по (клиент, инициалы) между раундами. Это противоречит прежнему «Response никогда не ссылается на человека» — нужен явный ключ `respondent_ref` только для неанонимных раундов.
5. **Шаблон по безопасности зафиксирован шефом:** 22 вопроса Forms дословно. Ассистент не должен «улучшать» формулировки якорных вопросов; правка якорного вопроса = новый anchor_key.
6. **Отчёты шефа живут в Excel.** Экспорт в формат Master_Analyse (этап 1 или 5) — чтобы не ломать его рабочий процесс.

Решения Oleksandr от 11.10 (трое без ролей, до 5 семинаров, без Graph, букмол, без SaaS, DPA проверить) остаются в силе.
