# Реестр классов данных и сроков хранения (0.19)

Источник — `docs/varde/adr/ADR-017-retention-by-data-class.md` (таблица «Сроки по классам» и строки «Backup-копии», «Логи», «Технические таблицы этапа 0», «Импортированные данные kartlegging»), ADR-024 (копии вне Varde), ADR-016 (бэкап). Машиночитаемая версия — `varde/config/retention.json` (схема `varde/apps/api/src/modules/retention/retention.config.ts`); тест `varde/tools/docs/test/retention-doc.test.ts` сверяет первую колонку обеих таблиц с ключами конфига (в обе стороны). Задачи удаления — 1.31 (`retention`-jobs), `forget`/`handover` — 1.31b.

Состояние на 13.10: бэкап (0.10), restore-drill и runbook восстановления (0.10d) отложены решением Oleksandr 13.10 — строки бэкапа и `restore-kopi` описывают правило, которое начнёт действовать, когда бэкап включат. Escrow секретов нет (решение 13.10).
